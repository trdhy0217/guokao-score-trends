# 国考历年岗位分数线可视化分析平台

## 一、项目概述

本项目旨在构建一个基于 GitHub Pages 部署的国考历年岗位分数线查询与趋势分析平台。

通过解析 `/data` 目录下的历年国考岗位分数线 Excel（`.xlsx`）文件，实现多年度数据整合、岗位精准检索、历年分数线趋势对比及交互式可视化展示，为用户提供直观、高效、便捷的国考岗位分数线查询服务。

## 二、技术角色

你是一名资深全栈工程师，具备数据清洗、前端开发、数据可视化及 GitHub Pages 部署经验。

请根据本 README 中的需求，完成项目的技术选型、架构设计、数据处理、页面开发、功能测试及部署配置。

## 三、核心功能需求

### 1. Excel 数据读取与标准化

- 自动扫描 `/data` 目录下所有 `.xlsx` 文件。
- 识别各文件对应的考试年份。
- 提取部门名称、职位名称、职位代码、部门代码、最低进面分数线等关键字段。
- 兼容不同年度 Excel 文件中可能存在的字段名称、格式及表头差异。
- 对原始数据进行清洗、去重、标准化处理。
- 建立统一的数据结构，支持跨年度数据关联与查询。
- 对缺失数据、异常分数及无法匹配的岗位进行合理处理，并保留必要的数据质量记录。

### 2. 多维度岗位检索

提供以下检索方式：

**方式一：部门名称 + 职位名称**

- 支持按部门名称检索。
- 支持部门名称与职位名称组合查询。
- 支持关键词模糊匹配与搜索建议。
- 可筛选具体考试年份。

**方式二：岗位编号检索**

- 支持输入职位代码进行精准匹配。
- 支持通过部门代码与职位代码组合定位岗位。
- 对同名岗位、同代码但不同年份的记录进行合理区分。

查询结果应展示岗位基础信息及对应年份的分数线数据。

### 3. 历年分数线趋势分析

根据用户选定的岗位，自动生成历年分数线折线图。

图表要求：

- X 轴：考试年份。
- Y 轴：最低进面分数线。
- 展示各年度对应的分数值。
- 支持鼠标悬停查看详细信息。
- 支持切换查询岗位。
- 支持按年份范围筛选。
- 对缺失年份采用断点展示，不得自动补造数据。
- 支持图表下载或导出。

**特别注意：** 不同年度的职位名称或代码不一定完全一致。跨年岗位匹配应采用可靠规则，无法确认属于同一岗位时，不得强行合并。同时，应注意不同岗位或考试类别的分数口径是否具有可比性。

### 4. 数据查询结果展示

查询结果以表格形式呈现，至少包含：

| 字段 | 说明 |
|---|---|
| 考试年份 | 对应国考年度 |
| 部门名称 | 招录部门 |
| 职位名称 | 具体岗位名称 |
| 部门代码 | 部门唯一识别编号 |
| 职位代码 | 岗位识别编号 |
| 最低进面分数线 | 对应年度分数 |
| 数据来源 | 对应 Excel 文件 |

支持结果排序、筛选和分页。

### 5. 页面交互与视觉设计

采用现代化、简洁、专业的数据分析平台设计风格。

- 首页展示平台名称、数据覆盖年份及检索入口。
- 检索区提供清晰的搜索框和筛选组件。
- 结果区展示岗位信息、分数线表格及折线图。
- 采用响应式布局，兼容电脑、平板和手机。
- 提供加载状态、空数据提示及错误反馈。
- 优化页面交互流畅度与图表可读性。

## 四、技术架构要求

优先采用与 GitHub Pages 兼容的纯静态前端架构。

**推荐技术栈：**

- 前端框架：React + TypeScript
- 构建工具：Vite
- UI 样式：Tailwind CSS
- 可视化：ECharts
- Excel 处理：Python + pandas + openpyxl
- 数据存储：预处理生成的 JSON 文件
- 部署平台：GitHub Pages
- 自动部署：GitHub Actions

Excel 文件应在构建前进行解析和预处理，前端直接加载生成的 JSON 数据，避免依赖必须持续运行的后端服务。
